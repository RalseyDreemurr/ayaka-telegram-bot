# Лицензии зависимостей

Код и документация Ayaka распространяются по [MIT License](../LICENSE).
Репозиторий содержит исходники Аяки, тестовые данные, шаблоны и документацию.
Python-пакеты устанавливаются отдельно из [requirements.txt](../requirements.txt).
Бинарники, код из установленных пакетов, драйверы, веса моделей и сторонние
медиа в репозиторий не включены.

Ниже лицензии 21 зафиксированного Python-пакета по метаданным установленных
дистрибутивов и прилагаемым файлам лицензий.

| Лицензия | Пакеты |
| --- | --- |
| MIT | aiogram, annotated-types, attrs, magic-filter, pydantic, pydantic-core, typing-inspection |
| Apache-2.0 | aiofiles, aiohttp-socks, aiosignal, frozenlist, multidict, propcache, python-socks, yarl |
| Apache-2.0 и MIT | aiohttp, включая прилагаемую лицензию llhttp |
| BSD-3-Clause | idna, python-dotenv |
| PSF-2.0 | aiohappyeyeballs, typing-extensions |
| MPL-2.0 | certifi |

Ollama — внешняя программа со своей [лицензией MIT](https://github.com/ollama/ollama/blob/main/LICENSE).
У рекомендованной модели Qwen3-8B своя [Apache-2.0](https://huggingface.co/Qwen/Qwen3-8B/blob/main/LICENSE).
У моделей, Tor и драйверов, которые пользователь устанавливает отдельно,
действуют их собственные условия. При распространении их копий сверяйте
лицензии конкретных версий.
