# Журнал изменений

## v2.0.0 · кандидат на первый официальный релиз

### Переносимость и документация

- Включена лицензия MIT с авторством RalseyDreemurr.
- Добавлен явный выбор прямого подключения к Telegram или SOCKS5. Старые
  конфигурации с SOCKS5 сохраняют маршрут.
- Ручной запуск работает без Fish и systemd. Службы используют Tor только
  для настроенного локального SOCKS5.
- Подготовлены инструкции для Arch Linux WSL с Windows Ollama, нативного Arch,
  Ubuntu и Debian, включая диагностику AMD Radeon через Vulkan.


### Общение

- Русскоязычная личность Аяки и ответы через локальную Ollama.
- Личные ответы владельцу, проверенному по числовому Telegram ID.
- Упоминания, ответы на реплики, `/callme` и ограниченная инициатива в группах.

### Память и приватность

- Раздельная история чатов, долговременная память, сводки и двухуровневый дневник.
- Архив групп включается после согласия. Индивидуальный отказ удаляет
  сохранённые данные участника и исключает дальнейшую запись.
- Чистая инициализация SQLite, настраиваемый `DB_PATH` и резервное
  копирование через SQLite Backup API.

### Установка и эксплуатация

- Конфигурация для Arch Linux WSL, Fish, systemd и Windows Ollama.
- Tor SOCKS5 с предварительной проверкой маршрута, ограниченные повторы
  соединения и штатная остановка с сохранением позиции polling.
- Шаблоны `.env` и `torrc` без рабочих ключей и мостов.
